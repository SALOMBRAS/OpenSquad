# Identidade visual — Rico Pneus (carrosséis)

**Uso obrigatório** nos steps de design e render: paleta e tipografia abaixo. Harmonizar com a percepção visual do **site ricopneus.com.br** e do feed **@rico_pneus** (fotografia real, ambiente escuro/profissional, destaque em vermelho quando houver CTA). Não usar azul ou verde como cor principal de acento (reservar para semântica eventual: só se o brief pedir).

**Layout estrutural:** [`carousel-layout-rules.md`](carousel-layout-rules.md). **Composição (título + gráfico + legenda):** [`carousel-visual-reference.md`](carousel-visual-reference.md). **Padrão editorial do cliente (Instagram Rico):** destaques `.accent` / `.gold` / `.hl` e bolinhas — ver [`client-carousel-design-standard.md`](client-carousel-design-standard.md).

## Paleta principal

| Uso | Cor | Hex |
|-----|-----|-----|
| Fundo escuro | Preto | `#000000` ou `#0a0a0a` |
| Texto em fundo escuro | Branco | `#FFFFFF` |
| Acento / CTAs / destaques | Vermelho automotivo | `#C62828` ou `#E53935` |
| Acento secundário (opcional) | Âmbar / alerta | `#F9A825` (uso pontual) |
| Fundo claro | Off-white | `#FAFAFA` |
| Texto em fundo claro | Preto / cinza escuro | `#0a0a0a` / `#18181B` |
| Texto secundário | Cinza | `#71717A` / `#A1A1AA` |

## Complementares

- Overlay escuro para legibilidade sobre fotos: `rgba(10,10,10,0.55)` a `0.85`.
- Evitar roxo/lavanda como identidade principal (não faz parte do core Rico Pneus); se o HTML legado usar traço colorido no topo, preferir **vermelho escuro** `#B71C1C` ou neutro.

## Rodapé e badge (ver também [`carousel-branding-rico-pneus.md`](carousel-branding-rico-pneus.md))

- **Rodapé:** texto fixo de marca Rico Pneus (ex.: `Rico Pneus · Fortaleza · CE`).
- **Badge** (opcional no topo): `Qualidade · Pneus` ou apenas logo/nome curto — nunca texto de outras marcas ou Insta MVP.

## Tipografia

- **Títulos:** sans-serif forte (Montserrat 800/900, Inter 800 ou similar).
- **Corpo:** Inter / Source Sans 400–600.
- Destaques: sublinhado ou pill na cor de acento; manter hierarquia clara (ver `design-system-instagram-regras-gerais.md`).
