# Banco de imagens gratuitos — Rico Pneus

## Fontes permitidas (100% gratuitas para uso em peças sociais)

1. **Unsplash** — https://unsplash.com — licença Unsplash (uso comercial permitido; atribuição apreciada).
2. **Pexels** — https://www.pexels.com — licença Pexels.

**Não usar** bancos pagos, “free trial” com watermark, ou imagens sem licença clara.

## Processo para o agente de fundos (Patricia / background-designer)

1. Escolher imagens alinhadas ao **tema do carrossel** (estrada, oficina, pneu em contexto, frota, detalhe técnico abstrato, etc.) — **nunca** imagens que sugiram **pneu de moto** se o tema não for claramente automotivo pesado (e mesmo assim evitar moto: a loja não vende pneu de moto).
2. Registrar em **`background-manifest.md`** no run:
   - URL da página da foto (Unsplash/Pexels)
   - Nome do fotógrafo / fonte (para crédito opcional na legenda interna ou no manifest)
   - Palavra-chave de busca usada
3. Baixar resolução suficiente para **1080×1440** (mínimo largura 1080px na maior dimensão).
4. **Não** incorporar watermark de stock; usar apenas downloads oficiais.

## Combinação com identidade

- Aplicar overlays (`linear-gradient`, vinheta leve) para harmonizar com [`design-system-rico-pneus-colors.md`](design-system-rico-pneus-colors.md).
- Fotos devem combinar com o **título e o contexto** do `carousel-draft.md`.
