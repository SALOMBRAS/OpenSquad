# Anti-patterns — Rico Pneus

## Nunca fazer

1. **Mencionar venda, troca ou dicas de pneus para motos** — fora do escopo comercial da loja.  
2. **Comparativo entre marcas** (“marca X é melhor que Y”) sem metodologia e fonte verificáveis.  
3. **Prometer resultado econômico exato** (“vai economizar X%”) sem base citável.  
4. **CTA poluída** no último slide: salvar + comentar + DM + site + ligação na mesma peça.  
5. **Alarmismo** que induza pânico ou irresponsabilidade (ex.: “vai estourar”) sem nuance e sem orientação segura.  
6. **Jargão técnico sem tradução** em todo o carrossel — perde o público particular.

## Sempre fazer

1. **Um foco por slide**; narrativa linear até o CTA.  
2. **Alinhar** com `brand-rico-pneus.md` e tom escolhido no checkpoint.  
3. **Distinguir** quando o conselho é para **uso particular** vs **frota** (1 frase quando necessário).  
4. **Reforçar confiança** com canal humano (WhatsApp, loja física) quando o CTA for conversão.
