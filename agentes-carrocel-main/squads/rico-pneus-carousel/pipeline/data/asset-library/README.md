# Asset library — composição de fundos (Rico Pneus)

Coloque aqui **ativos raster ou vetoriais exportados** que Eduardo Compositor pode sobrepor nas imagens brutas:

- **Ícones** (PNG/SVG) — preferir fundo transparente.  
- **Fumaça, névoa, poeira** — PNG com alfa.  
- **Formas** — balões vazios, molduras discretas.  
- **Formatos:** `png`, `svg` (exportar para PNG antes do composite se o pipeline usar só raster).

**Obrigatório por arquivo ou por pasta:** um pequeno `LICENSE.txt` ou comentário no `composite-layer-manifest.md` com **fonte + licença** (ex.: “Kenney.nl CC0”, “icone Flaticon licença free com atribuição em manifest”).

Não commitar arquivos gigantes sem necessidade; otimizar para ~1080px de largura útil quando possível.
