# Content Contracts

Required run outputs for content stage:

- `research-ranking.md`: ranked topics with source/date/url/reason.
- `selected-topic.md`: user-selected topic payload.
- `seo-brief.md`: keyword plan, search intent, promise, constraints.
- `angles.md`: 3-5 narrative angles.
- `selected-angle.md`: chosen angle.
- `selected-tone.md`: chosen tone.
- `selected-cta.md`: chosen CTA.
- `selected-headline.md`: approved cover headline.
- `carousel-draft.md`: slide-by-slide copy plus draft caption.
- `caption-final.md`: final SEO-optimized caption.
